# 叶圆片实验：眼镜指导测试指南

[打开协议](./protocol.aimd)。中文版，19 个步骤；完整三轮约 120–150 分钟，每轮 L/W/D 三杯各 10 片。先空杯排练，经实验室安全审核和叶材/光源预实验后开展真实实验。方法来源和参数改编说明见协议末尾。

## 适合测试的能力

| 场景 | 排练方式 | 预期行为 |
| --- | --- | --- |
| 杯号与处理匹配 | 将空杯 L1/W1 交换位置 | 依标签而不是左右位置确认身份 |
| 计时与重复动作 | 模拟负压浸润循环 | 每次明确开始/释放，达到 5 次上限仍不合格时停止并请求处理 |
| 并行任务 | 用纸片模拟 L/W 计数，同时放置遮光 D 杯 | 分别提示杯号和时间，不要求逐分钟打开 D |
| 反光与重叠 | 用纸圆片和透明杯模拟遮挡 | 请求人工复核，接受 7 改为 6，保留纠正记录 |
| 漏测 | 故意跳过一个模拟分钟 | 保留缺失，不补 0 或生成一个“平滑”计数 |
| 中断恢复 | 暂停界面但让独立秒表继续 | 恢复后记录真实经过时间，不重置生物过程时间轴 |
| 未达到 ET50 | 使用不到 5/10 上浮的模拟序列 | 记录观察期内未达到，端点留空，不填 0 或强行填 30 分钟 |
| 对照受干扰 | 以事件输入模拟 D 杯被开盖 | 保留终点数据并标记受干扰，不计算 D 的 ET50 |

以上故障注入只用空杯、纸片或模拟记录；不要为测试制造电液接触或暴力拉动注射器。模拟计数不得合并到真实实验 Record。

## 数据与集成边界

- `cup_setup`、`observations`、`endpoints`、`et50_results` 通过唯一 `cup_id` 关联；`round_no` 区分重复。同杯叶片不是独立重复。
- 时间序列的 `elapsed_s` 从本轮开始计算；交互事件的 `elapsed_s` 从本次运行开始计算。宿主同步时须保留该区别。
- 界面自动汇总只累计显式计时项，不会把 30 分钟窗口乘以重复轮数；完整实验排期以协议开头的 120–150 分钟为准。
- L/W 保存分钟级实际计数；D 只做初始检查和终点观察。ET50 使用观测区间，缺失、不适用、无可靠估计与 0 明确区分。
- 所有杯号一致性、每轮完整性、时间顺序和科学质控均需人工/宿主复核。本例字段约束不能代替跨表校验。
- 可空字段未填写时使用显式 `null`，交给 Python 生成模型时保留对应键。草稿不完整不等于正式记录已通过校验。
- 视觉计数、语音控制、自动定时提醒及证据采集是后续宿主能力；当前无需 Engine，可直接在 Recorder 手工填写。没有模拟硬件接口或自动结果计算。

软件验证不等于湿实验验证。后续眼镜验收可记录杯号误认率、计数误差、漏测提醒率、人工纠正成功率、暂停恢复后的时间轴偏差，并由实验人员复核原始证据。
