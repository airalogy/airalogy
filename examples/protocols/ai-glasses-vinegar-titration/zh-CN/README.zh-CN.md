# 白醋滴定：眼镜指导测试指南

[打开协议](./protocol.aimd)。中文版，18 个步骤，预计 75–100 分钟。用已标定稀 NaOH 测定透明白醋的总可滴定酸度；先清水排练，再经实验室审核开展真实实验。方法参考与改编边界见协议末尾。

## 适合测试的能力

| 场景 | 排练方式 | 预期行为 |
| --- | --- | --- |
| 顺序与漏步 | 使用空器具，尚未确认移除漏斗就请求下一步 | 指出待确认项目，不伪造检查结果 |
| 数值与单位 | 用纸上刻度卡模拟 1.25 mL，被转写成 12.5 mL | 复述数值和单位，接受纠正后保留纠正事件 |
| 小动作与视觉盲区 | 遮挡尖嘴或刻度卡 | 说明无法判断，要求重新观察，不把低置信度当作成功 |
| 终点计时 | 用预制颜色卡模拟淡粉后褪色 | 询问操作者判断，重新启动 30 秒确认，不自动合格 |
| 暂停恢复 | 清水排练时在正式试次中途暂停 | 先关闭阀门，恢复时核对瓶号、表格行和读数 |
| 错误与重做 | 用模拟记录表示过量或气泡 | 保留原始行及排除理由，转到新试次，不覆盖失败数据 |
| 质控失败 | 输入不满足极差条件的模拟试次 | 不把均值“正常”当作通过，不选择性删除偏离试次 |

故障注入只在清水、空器具或模拟输入下进行；不要在真实实验中故意取消防护、混淆试剂或造成泄漏。模拟数据必须使用独立排练 Record，不能冒充测量。

## 数据与集成边界

- `step` ID 是稳定的定位键；循环试次使用 `trial_id` 区分，不靠步骤勾选次数计数。
- 界面自动汇总的时长只包含显式声明的计时项，不含未计时操作和重复循环；整体排期以协议开头的 75–100 分钟为准。
- `titrations` 保存原始液面、消耗、终点和纳入状态；`guidance_events` 保存距运行开始的时间、步骤 ID、问题和恢复位置。
- 证据图片/视频由宿主按取得同意的录制策略保管。可在事件描述中填写证据编号，但本例不会自动录制或上传。
- Recorder 支持手工录入、计时、勾选及草稿保存。语音、视觉、自动导航、强制关卡及跨字段科学质控由宿主另行实现；字段类型校验不等于 SOP 审核。
- 本例无 Assigner，无自动结果计算；公式演算值仅用于核算公式。关键实测值、通过状态和检查点均不预填。
- 可空字段的未填写值使用显式 `null`。交给 Python 生成模型校验时，不要把可空字段的键直接省略；草稿可以不完整，正式记录由宿主补齐表示并校验。

软件测试只验证加载、解析、字段与约束，不证明滴定准确度、眼镜识别率或湿实验可重复性。现场验收应另记录任务完成率、错误识别/漏报数、人工纠正数、恢复位置准确率及原始证据。
